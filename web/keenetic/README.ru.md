# Веб-панель Keenetic

<!-- ai-generated: complete Keenetic web control plane guide. -->

Небольшая панель управления для Entware. Она не содержит собственной копии ядра olcRTC и вызывает только заранее заданные служебные команды без shell.

Возможности первой версии:

- проверка реального состояния клиента и SOCKS;
- запуск, остановка и перезапуск клиента;
- сквозная диагностика;
- импорт canonical `olcrtc://` URI через строгий helper;
- просмотр журнала с удалением ключей и токенов;
- пароль scrypt, короткие сессии, CSRF, Origin check и rate limit;
- запрет wildcard bind.

Ручная инициализация по умолчанию слушает `127.0.0.1:8091`. Установщик пытается определить IPv4 интерфейса `br0` и привязывает панель только к этому LAN-адресу. Для ручного доступа из домашней сети указывается конкретный адрес роутера и `allow_lan: true`. Привязывать панель к `0.0.0.0`, `::` или WAN нельзя.

Инициализация вручную:

```sh
/opt/bin/python3 /opt/lib/olcrtc-keenetic/web-app.py \
  --config /opt/etc/olcrtc-keenetic/web.json \
  init
```

Запуск:

```sh
/opt/bin/python3 /opt/lib/olcrtc-keenetic/web-app.py \
  --config /opt/etc/olcrtc-keenetic/web.json \
  run
```

Entware-установщик создаёт конфигурацию и службу автоматически. Доступ с публичного WAN не поддерживается. Для удалённого управления используйте отдельный доверенный VPN или SSH tunnel.
